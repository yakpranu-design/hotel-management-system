# 🏨 Hotel Management System

A complete Hotel Management System developed using HTML, CSS, JavaScript and Firebase Firestore.

## 🚀 Features

- 🔐 Admin Login
- 👥 Customer Management
- 🍽️ Menu Management
- 📝 Daily Food Entry
- 💰 Weekly Bill Generation
- 📲 WhatsApp Bill Sharing
- 🖨️ Print Bill
- 💳 Payment Management
- 📊 Reports
- 📒 Customer Ledger
- 📦 Stock Management
- 📈 Dashboard Statistics

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Firebase Firestore
- Vite
- Git
- GitHub
- Netlify

